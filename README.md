# 🫘 Bean Scene

**Bean Scene** — это лендинг для кофейни с современным дизайном, плавной прокруткой и стильными секциями.

![styled-components](https://img.shields.io/badge/styled--components-DB7093?style=flat&logo=styled-components&logoColor=white)

---

## 📄 Секции

- **Hero** — первый экран «We have got your morning covered with Coffee» с кнопкой заказа
- **Discover** — блок «Discover the best coffee» о кофейне
- **Меню** — карточки напитков «Enjoy a new blend of coffee style»
- **Призыв к заказу** — «Get a chance to have an Amazing morning»
- **Отзывы** — блок с отзывом покупателя
- **Футер** — подписка на новости, навигация, контакты и соцсети

---

## ✨ Особенности

- Стилизация через styled-components
- Немного измененная FSD архитектура с компонентами в папке `features`
- Шрифты Playfair Display и Clicker Script через `next/font/google`: загружаются без сдвига вёрстки
- Иконки соцсетей — собственные SVG-компоненты

---

## 🛠️ Технологии

- React + TypeScript
- styled-components
- Next.js 15 (App Router)

---

## 📦 Установка и запуск

```bash
git clone https://github.com/donuwave/bean-scene-next.git
cd bean-scene-next

npm install
# или
yarn install

npm run dev
# или
yarn dev
```
